# Tests

`test_screening_self_test.sh` invokes the synthetic regression suite embedded in
the frozen v3.2.5 registry-screening program.

The embedded suite tests resistance-marker matching, copy-number language,
host-response versus direct microbial analytes, named bacterial assays,
mixed viral-bacterial panels, diagnostic routing, and expected diagnostic-depth
assignments for synthetic ClinicalTrials.gov-style records.
